# 🎮 Word Game App

**Word Game** is a fun two-player browser game where players take turns guessing a hidden word. A few letters are revealed, and each player gets up to **5 chances** to correctly guess the word before the game ends.

---

## 🕹️ How to Play

- The game displays a word with some letters filled in and the rest hidden as empty boxes (`_`).
- Two players take turns guessing the word.
- Each player gets **5 chances** to guess.
- If a correct guess is made, the game is won!
- If all chances are used, the game ends and the correct word is revealed.

---

## 🚀 Features

- ✍️ Interactive input with keyboard or mouse
- 🔄 Turn-based logic for two players
- 🔢 Limited guess system (5 tries each)
- 🎨 Stylish UI with custom CSS animations
- 💡 Dynamic hint-based letter revealing
- 💬 Win/Loss result messages with score tracking (optional)
